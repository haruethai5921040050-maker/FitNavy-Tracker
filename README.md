# ⚓ FitNavy - Smart Calorie & Weight Tracker

เว็บแอปพลิเคชันติดตามแคลอรี อัตราการเผาผลาญ และบันทึกน้ำหนักรายวัน ออกแบบเพื่อการใช้งานบนมือถือ (Mobile-First)

## 🚀 ฟีเจอร์หลัก (Key Features)
- **ระบบโปรไฟล์ & เข้าสู่ระบบ:** บันทึกและดึงข้อมูลแยกตามผู้ใช้งาน
- **ระบบคำนวณอาหาร:** รองรับหน่วยกรัม (g) และมิลลิลิตร (ml) คำนวณแคลอรีอัตโนมัติ
- **Batch Food Add:** เลือกอาหารหลายรายการและรวมบันทึกลงมื้อเดียว
- **AI Menu Suggestion:** สุ่มแนะนำเมนูสุขภาพตามแคลอรีคงเหลือ
- **Smart Calorie Buffer:** ล็อกโควตาพลังงานมื้อเย็นไม่ให้ต่ำกว่า 350 kcal
- **Exercise Compensate:** คำนวณเวลาออกกำลังกายชดเชยเมื่อทานเกินโควตา
- **Daily Checklist:** สรุปการกินอาหารครบ 4 มื้อ และเตือนชั่งน้ำหนักรายวัน

## 🛠 Tech Stack
- **Backend:** Google Apps Script, Google Sheets
- **Frontend:** HTML5, Tailwind CSS
